# Red-team pass — 2026-08-05

Adversarial self-audit assuming a hostile expert reviewer. Run at build close, over
614 nodes / 1,181 edges / 288 gaps / 1,049 references.

Reproduce: `python3 atlas/tools/redteam.py --all`

**Two of the six checks turned out to be measuring their own thresholds rather than the
atlas.** That is recorded here as a finding about the audit, not quietly fixed and
forgotten, because a check that cries wolf stops being read and then stops protecting
anything.

## 1. Reference provenance — the anti-fabrication guarantee, checked

| | |
|---|---:|
| machine-populated by `addref.py` from a live Europe PMC/NCBI record | **1,005** |
| manual / non-indexed (GEO accessions, regulatory dossiers), flagged `verify_by_hand` | 44 |
| **hand-written with no machine signature** | **0** |

Zero references in this atlas have author, year or title typed from memory. That is the
single load-bearing claim of the whole design and it holds at build close.

The 44 manual entries are the weak link by construction — GEO accessions, FDA labels and
trial-registry entries have no Europe PMC record to resolve against — and every one
carries `verify_by_hand: true` so it stays visible as such.

## 2. Species laundering — 51 flags, 0 defects, and why the flags should stay

Forty-nine flags are advisory (`!`): the node's `species_basis` is animal-only while its
summary uses a phrase like "in humans" or "human growth plate". Sampled across the list,
every instance is the summary *stating the species gap* — "no equivalent measurement
exists for any human growth plate", "has never been tested in human tissue". The check
cannot distinguish asserting a human fact from denying one, and it should not be taught
to: the phrase it matches is exactly the phrase a laundered claim would use.

Two hard flags (`✗`), both **reviewed and accepted**:

| node | flag | disposition |
|---|---|---|
| `cartilage_organoid` | `human_evidence: direct` with `species_basis: [ipsc_derived, in_vitro_human_cell]` | **Accepted.** The node's own `human_evidence_note` already says it: *direct human evidence about the trajectory, not about the organ*. `translation_risk: moderate` carries the in-vitro caveat. |
| `ipsc_chondrogenesis` | same | **Accepted.** Note reads *the evidence is human but the developmental stage is fetal-like*. |

The check was **not** weakened to silence these. It is right to surface them every run,
and 2 of 353 direct-human nodes being in-vitro human material is a composition fact a
reader of `human_evidence_fraction` should be able to find.

## 3. Hedging — the check was wrong, twice over

**First pass: 29 hits across 614 nodes, and a manual read of all 29 found zero real
hedged conclusions.** The hits were:

- the month **"May 1945"** (`dutch_hunger_winter`);
- literal capability, not hedging — *"12.5% of secondary colonies **could be passaged**
  nine times"*, *"the gap this dataset **could** close"*;
- a hedge that the same sentence resolves — *"advanced bone age **might be expected** to
  cost adult height **but does not**"*;
- and correctly-scoped statements about the state of the evidence, which the atlas
  exists to make.

Precision 0/29. The rule bans a hedge **as a conclusion**, so the check now reads only
the final sentence of each summary. That drops it to **7**, and those 7 are also all
legitimate — closing lines like *"the human proliferative cell cycle appears to be one to
two orders of magnitude slower"* and *"CNP analogues may alter callus consolidation, so
the interaction is a live surgical question"*.

**Stated without spin: this check has never found a true positive in 614 nodes.** Two
readings are available and the audit cannot distinguish them — either the corpus is
genuinely clean because every uncertain statement is scoped to its evidence or converted
to a gap entry, or the check cannot detect the failure mode it is aimed at. It is kept
because 7 reviewable lines per run costs nothing.

## 4. Gap admissibility — one false positive, from a length heuristic

`g_l1arch_003` was flagged *"query string too vague to reproduce"* because its query,
`septoclast*`, is 11 characters and the check demanded 15.

It is a single-term wildcard search that anyone can paste into Europe PMC and get the
same 54 hits, with all 54 screened and every primary observation named by PMID. The
check was testing **length** when the property that matters is **reproducibility**. It
now rejects an empty string, a prose description of a search ("searched for several
terms"), or a short string with no query syntax — and accepts a short query that carries
a wildcard, a boolean, a field or a quoted phrase.

**288 gaps, 0 inadmissible.** Every `search_established` gap carries a re-runnable query,
a date, a hit count and a stated reason nothing qualified.

## 5. Weak quantitative rows — 138, and these are real

This is the finding that survives review, and it is a property of the field rather than
of the build.

| | rows |
|---|---:|
| flagged `value_unverified` | **40** |
| sourced from an **abstract only** | **98** |

Abstract-only sourcing is concentrated exactly where it hurts most. `npr2_receptor`
carries seven such rows — every human NPR2 stature figure in the atlas, including the
adult-height numbers for biallelic loss of function and the height-SDS range for
dominant-negative carriers. `zonal_stiffness_gradient` carries five, covering the entire
zonal mechanical record. `schmid_metaphyseal_chondrodysplasia` carries five, including
the linkage lod score that anchors an A-grade node.

The reason is the one the context-fill campaign measured independently: **515 of 783
cited references are abstract-only because the paper is not open access.** No amount of
curation fixes that from outside a paywall, and `atlas/sources/access_queue.md` is where
the items worth escalating are held.

These rows are not defects — they are correctly labelled — but any downstream number
that leans on them inherits an uncertainty nobody has been able to check against a
methods section.

## 6. What this pass did not do

- **It did not re-read primary sources.** `redteam.py --sample N` exists to draw a
  seeded, reproducible sample for exactly that manual pass, and it has not been run at
  scale. Every finding above is mechanised, and the failure mode that most needs a human
  — *does this source actually say what the node claims* — is the one least covered here.
- **It did not audit the 26 orphan non-stub nodes** one by one. They are reported on
  every validator run and most are L13 methods entities that legitimately have no
  mechanistic edge, but "most" is an estimate.
- **It found nothing that changed a grade.** Zero corrections opened, zero confidence
  levels moved. Read that alongside the fact that the two audits run this build which
  *did* change things — the canonical-mechanism audit (2 superseded, 6 scoped) and the
  paralog attribution sweep (9 at risk) — both worked by **reading primary sources**,
  not by pattern-matching the repository. That is the honest lesson of this pass.
