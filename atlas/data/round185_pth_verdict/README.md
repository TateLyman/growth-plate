## The benchmark that decides it

The sign of this drug class **inverts with schedule**. "Intermittent" is a ratio between the dosing
interval and the clock of the target cell — and the atlas holds both clocks.

| | doses/week | **pulses per chondrocyte cell cycle** |
|---|---|---|
| `ogawa2002` rat (cycle 1.4 d) | 5 | **1.0** |
| teriparatide / abaloparatide **DAILY** (human, cycle ~20 d) | 7 | **20.0** |
| twice-weekly | 2 | 5.7 |
| weekly 56.5 µg (approved, Japan/China) | 1 | 2.9 |
| every 3 weeks | 0.33 | **1.0** ← matches the rat |

**Daily dosing is 20× too frequent relative to the human chondrocyte clock.** Robust: 10–30× across a
human cycle of 10–30 d; still 8–9× even at the slowest rat plate `wilsman1996` measured.

## What survives

Mechanism is still the only exact match to the amplification term. `huang2026`: PTHLH loss of function
→ short stature in humans, so the ligand is growth-positive. The Jansen reinterpretation stands.
**Weekly teriparatide is an approved product** and lands within ~3× of the rat schedule.

## What would collapse the benchmark

If intermittency is set by **PTH1R resensitisation** (receptor-intrinsic, species-invariant) rather
than the **chondrocyte commitment clock** (scales with cell cycle), the whole argument fails. Nobody
has measured PTH1R resensitisation in a chondrocyte of either species — gap
`g_l12_which_clock_sets_intermittency_at_the_growth_plate` specifies the two experiments.

**Still needed and blocked:** `ogawa2002` full text (J Bone Miner Metab 2002, PMID 11862529) — paywalled.
