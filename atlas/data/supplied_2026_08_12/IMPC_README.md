# IMPC Reports

This FTP folder contains a collection of CSV reports generated by the IMPC ETL process. Each report provides a summarised or processed view of IMPC data, covering topics such as genotype-phenotype associations, fertility, viability, gene expression, and phenotyping completeness. These reports are produced from a snapshot of the current data for every new data release.

## General Changes and Updates

The following changes apply across multiple reports or reflect global differences compared to the original Java-generated reports:

- **`p_value` formatting:** In the original reports, the `p_value` field used a lowercase `e` in scientific notation (e.g. `1.2e-5`). The new reports use an uppercase `E` (e.g. `1.2E-5`).
- **Report splitting:** Several original reports contained multiple tables concatenated into a single file. These have been split into numbered sub-files (e.g. `fertility-1-summary.csv`, `fertility-2-conflicting.csv`, `fertility-3-detailed.csv`). Commands to reproduce the original combined files are provided in each relevant section below.

## Reports

### Data Overview

**Original file:** `dataOverview.csv`

**Split into:**
- `data-overview-summary-1.csv.gz` — global counters including total genes, lines, phenotype hits, data points, and images, as well as per-centre line counts.
- `data-overview-2-top-level-mp.csv.gz` — for each top-level MP term, shows how many associated genes have undergone "complete" phenotyping (defined as 13 or more procedures performed), as a percentage of all genes associated with that term.
- `data-overview-mp-3.csv.gz` — the same completeness calculation as above, but broken down by individual MP term rather than top-level category.

**Description:**
A high-level summary of the current data release. It reports key metrics — how many genes and mouse lines have been phenotyped, how many phenotype associations have been found, and how much image data is available. It also shows, for each phenotype category, what proportion of associated genes have been thoroughly screened.

**Updates:**
- No specific updates beyond the report being split into three separate files.

**Reproducing the original combined report:**
```bash
gzip -d data-overview-1-summary.csv.gz data-overview-2-top-level-mp.csv.gz data-overview-3-mp.csv.gz && \
cat data-overview-1-summary.csv > dataOverview.csv && \
echo '""' >> dataOverview.csv && \
cat data-overview-2-top-level-mp.csv >> dataOverview.csv && \
echo '""' >> dataOverview.csv && \
cat data-overview-3-mp.csv >> dataOverview.csv
```

### Fertility Report

**Original file:** `fertility.csv`

**Split into:**
- `fertility-summary-1.csv.gz` — counts of distinct genes per fertility status (fertile / infertile) and per sex (male / female / both).
- `fertility-conflicting-2.csv.gz` — list of genes that appear in more than one fertility category.
- `fertility-detailed-3.csv.gz` — every individual fertility observation, with a "Conflicting Data" comment flag added to rows where the gene appears in the conflict list.

**Description:**
This report contains information about the reproductive outcomes of gene knockout mouse lines. It uses two specific measurements: one for male fertility (`IMPC_FER_001_001`) and one for female fertility (`IMPC_FER_019_001`). The report identifies which genes result in infertility, highlights cases where the same gene has produced contradictory fertility results across different experiments, and provides a full record of every individual observation.

**Updates:**
- `fertility-detailed-3.csv.gz` was fixed so the number of data columns matches the header, by correctly including the `comment` column. This column carries the "Conflicting Data" flag where applicable.

**Reproducing the original combined report:**
```bash
gzip -d fertility-1-summary.csv.gz fertility-2-conflicting.csv.gz fertility-3-detailed.csv.gz && \
cat fertility-1-summary.csv > fertility.csv && \
echo '""' >> fertility.csv && \
cat fertility-2-conflicting.csv >> fertility.csv && \
echo '""' >> fertility.csv && \
cat fertility-3-detailed.csv >> fertility.csv
```

### Gene and MP Term Association

**Original file:** `geneAndMPTermAssociation.csv`

**Split into:**
- `gene-mp-association-1.csv.gz` — associations between genes and top-level MP terms, with zygosity information. Genes are displayed with their MGI IDs in parentheses. Zygosity is sorted in the following order: homozygote, heterozygote, hemizygote, anzygote, not_applicable, wildtype.
- `gene-mp-association-2.csv.gz` — viability summary per gene per phenotyping centre, showing homozygous, heterozygous, and hemizygous counts, all observed viability categories, and a direct link to the gene's page on the IMPC website.

**Description:**
This report provides a high-level overview of which genes are associated with which broad biological phenotype categories (top-level MP terms), and also summarises viability outcomes (whether the knockout is lethal, subviable, etc.) per gene per phenotyping centre.

**Updates:**
- Links in section 2 have been updated to resolve previously broken URLs:
  - Old format: `http://dev.mousephenotype.org/data/genes/MGI:XXXXXX`
  - New format: `https://www.mousephenotype.org/data/genes/MGI:XXXXXX`

**Reproducing the original combined report:**
```bash
gzip -d gene-mp-association-1.csv.gz gene-mp-association-2.csv.gz && \
cat gene-mp-association-1.csv > geneAndMPTermAssociation.csv && \
echo '""' >> geneAndMPTermAssociation.csv && \
cat gene-mp-association-2.csv >> geneAndMPTermAssociation.csv
```

### Genotype-Phenotype Assertions

**Files:**
- `genotype-phenotype-assertions-ALL.csv.gz`
- `genotype-phenotype-assertions-3I.csv.gz`
- `genotype-phenotype-assertions-EUROPHENOME.csv.gz`
- `genotype-phenotype-assertions-IMPC.csv.gz`
- `genotype-phenotype-assertions-MGP.csv.gz`

**Description:**
These reports list statistically significant associations between mouse genotypes and observed phenotypes. Each row represents one such association, along with details about the gene, the experimental setup, the specimens tested, and the statistical result (including p-value, effect size, and the method used).

The `ALL` file contains every significant association across all data sources. The remaining files are filtered versions containing only data from a specific resource:
- `3I` — current 3I lines
- `EUROPHENOME` — legacy EuroPhenome lines
- `IMPC` — current IMPC lines
- `MGP` — legacy Wellcome Trust Sanger Institute lines

**Updates:**
- The `project_fullname` field was always empty in the original reports (Solr retained the field name, but no data was present). This column was removed from new report.

### LacZ Expression

**File:** `laczExpression.csv.gz`

**Description:**
This report contains data on where a gene is expressed across different tissues and body parts, based on LacZ staining results from the Adult LacZ procedure. Each unique tissue measurement becomes its own column, and cell values indicate the expression result (e.g. "expression", "no expression"). The report also includes direct links to the IMPC website where wholemount and section images can be viewed for each gene.

**Updates:**
- Image links have been updated to resolve previously broken URLs (404 errors):
  - Old format: `https://www.mousephenotype.org/data/imageComparator?acc=MGI:XXXXXXX&parameter_stable_id=IMPC_ALZ_075_001`
  - New format: `https://www.mousephenotype.org/data/genes/MGI:XXXXXXX/images/IMPC_ALZ_075_001`

### Phenotype Hits per Gene

**File:** `phenotypeHitsPerGene.csv.gz`

**Description:**
A summary of significant phenotype associations. For each gene, it lists the phenotypes that were found to be significantly associated, along with the count of such hits. Genes that were tested but produced no significant hits are also included, providing a complete picture of what has been screened. LacZ-related parameters are excluded from this report.

**Updates:**
- The values in the `Phenotype Hits` column are now sorted alphabetically, improving consistency across releases.

---

### Phenotype Hits per Line

**File:** `phenotypeHitsPerLine.csv.gz`

**Description:**
Shows how significant phenotype hits are distributed across mouse colonies (lines). Only associations with a p-value of 0.0001 or below are counted. The report categorises hits by zygosity (homozygote, heterozygote, and combined) and shows how many colonies have 0, 1, 2, or more significant hits in each category.

**Updates:**
- No changes compared to the original report.

---

### Phenotype Hits per Parameter and per Procedure

**Files:**
- `phenotypeHitsPerParameter.csv.gz`
- `phenotypeHitsPerProcedure.csv.gz`

**Description:**
These reports answer the question: for a given measurement (parameter) or experimental test (procedure), which genes showed a significant phenotype? Each row corresponds to a parameter or procedure, and lists all genes that had a significant association with it. Gene symbols and their corresponding MGI identifiers are pipe-separated (`|`) and sorted alphabetically.

**Updates:**
- Empty lines have been removed from `phenotypeHitsPerParameter.csv`.
- Gene ordering is now standard alphabetic order. Previously, the Java implementation sorted capital letters before lowercase letters.

### Phenotype Hits per Top-Level MP Term

**Original file:** `phenotypeHitsPerTopLevelMPTerm.csv`

**Split into:**
- `hits-per-top-mp-annotations-1.csv.gz` — significance rates based on total statistical calls. Columns: `# Significant Calls`, `# Not Significant Calls`, `% Significant Calls`.
- `hits-per-top-mp-lines-2.csv.gz` — significance rates based on distinct colonies. Columns: `Lines Associated`, `Lines Tested`, `% Lines Associated`.
- `hits-per-top-mp-genes-3.csv.gz` — significance rates based on distinct genes. Columns: `Genes Associated`, `Genes Tested`, `% Genes Associated`.

**Description:**
These reports summarise how often genes and mouse lines are found to have phenotype associations within each top-level MP term. For example, how many genes tested for "nervous system phenotype" showed a significant result. Only IMPC and 3I data are included, and reproductive system phenotype terms are excluded. A p-value threshold of 0.0001 is used to define significance.

**Updates:**
- Percentage values are now rounded to four decimal places, compared to less consistent rounding in the original.

**Reproducing the original combined report:**
```bash
gzip -d hits-per-top-mp-1-annotations.csv.gz hits-per-top-mp-2-lines.csv.gz hits-per-top-mp-3-genes.csv.gz && \
cat hits-per-top-mp-1-annotations.csv > phenotypeHitsPerTopLevelMPTerm.csv && \
echo '""' >> phenotypeHitsPerTopLevelMPTerm.csv && \
cat hits-per-top-mp-2-lines.csv >> phenotypeHitsPerTopLevelMPTerm.csv && \
echo '""' >> phenotypeHitsPerTopLevelMPTerm.csv && \
cat hits-per-top-mp-3-genes.csv >> phenotypeHitsPerTopLevelMPTerm.csv
```

### Procedure Completeness and Phenotype Hits

**File:** `procedureCompletenessAndPhenotypeHits.csv.gz`

**Description:**
This report tracks how thoroughly each mouse colony and gene has been phenotyped. For every gene and colony, it shows which MP terms were tested and which produced a significant result. Results are broken down by zygosity (e.g. homozygous, heterozygous) and life stage. This makes it possible to assess which genes have been comprehensively screened and which may have gaps in phenotyping coverage.

**Updates:**
Two bugs from the original Java implementation were fixed:
1. Top-level MP term IDs were sometimes duplicated — this has been corrected.
2. Procedure and parameter counts were calculated incorrectly — these are now accurate.

### Statistical Results

**File:** `statistical-results-ALL.csv.gz`

**Description:**
A comprehensive dump of all statistical results produced by the IMPC statistical pipeline, including both significant and non-significant results. This report covers all phenotyping centres and pipelines that were successfully processed.

**Updates:**
The following columns were present in the original Solr-based report but contained no data. They have been removed from the new report:
```
procedure_id, mutant_biological_model_id, rotated_residuals_test,
control_selection_method, phenotyping_center_id, dependent_variable,
project_id, blups_test, null_test_p_value, control_biological_model_id,
organisation_id, external_db_id, db_id, resource_id,
pipeline_id, categories, parameter_id
```
- The `_version_` column (generated internally by Solr) no longer appears in the new report.
- The `intermediate_mp_term_name` field previously contained extraneous backslashes in some values. These have been removed.

### Viability Report

**File:** `viability.csv.gz`

**Description:**
This report describes whether each mouse line produced offspring in the expected proportions when bred, which indicates whether the gene knockout is lethal, reduces survival (subviable), or has no effect on viability. It covers both manually curated assessments (`IMPC_VIA_001`) and computationally derived ones based on pup counts (`IMPC_VIA_002`). Where a gene has been assessed at multiple centres or in multiple colonies with conflicting results, these conflicts are flagged. The percentage of homozygous and hemizygous pups is included to help identify relevant cases in X-linked genes.

**Updates:**
Two bugs from the original Java implementation were fixed:
1. A strict priority hierarchy for conflicting viability calls was implemented: **Lethal** takes precedence over **Subviable**, which takes precedence over all other categories. One gene (`Setbp1`) was affected — its record now correctly shows "Subviable" instead of "Reduced Life Span".
2. A `Zygosity` column was added to distinguish between homozygous and hemizygous records, resolving inconsistencies in X-linked gene data.
